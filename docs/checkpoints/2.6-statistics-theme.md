# 2.6 — Precise statistics and startup theme

Approved: daily / trailing seven days / calendar month statistics, Track filters,
Streak based on actual study dates, exact pause-aware midnight/month/year splits.
Also approved: neutral white/black 70%, green 25%, accent 5%, subtle glow and
interaction animation, preserving Thai/English and Light/Dark.

## Data contract

- New timer runs snapshot the profile timezone and capture one active segment per
  start/resume, closing it on pause/finish/deadline/discard. Never write per tick.
- Saved sessions allocate closed active segments to local dates. Local midnight
  uses named timezones, including 23/25-hour DST days.
- Whole credited seconds use cumulative active-millisecond boundaries, rounding
  once per session. Sum of daily allocations equals the saved duration exactly.
- Only saved study allocations count for Streak; breaks never count. Current
  Streak remains through yesterday until today ends; longest Streak is also shown.
- Track filters apply to study time. Break totals and Streak remain account-wide
  and are labelled accordingly.
- Existing runs/history lack complete pause timelines: retain totals/history,
  label legacy_unallocated, exclude uncertain dates from precise charts/Streak.
  No guessed backfill or automatic deletion.
- Timezone is captured at start, so later profile timezone edits do not rewrite
  previous study dates.

## UI contract

- /statistics: day, trailing 7 days, calendar month; previous/next/date controls,
  personal active/archived Track selection, interactive chart/details, empty
  states and clear legacy notice.
- Signed-in Dashboard uses real today/weekly/Streak data. Guest demo remains
  explicitly labelled. Goals/music remain separate future checkpoints.
- Shared startup CSS for Dashboard/Auth/Account/Tracks/History/Statistics.
  Neutral surfaces and typography dominate; green is the primary action/data
  color; violet is the small break/accent color. Soft hover glow, press feedback,
  opacity entrance, chart transitions, and prefers-reduced-motion support.
- Never put transformed/filtered ancestors around fullscreen content.
