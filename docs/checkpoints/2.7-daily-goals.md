# 2.7 — Daily Goals

Approved: create, edit, delete and manually complete personal daily goals,
optional Track association, today progress and historical dates.

## Contract

- /goals selects a calendar date, defaults to today from the database in the
  profile timezone. Previous/next/date input and Today link; 12 goals per page.
- Date is an explicit planning date. Creating/editing historical or future dates
  is allowed. Date/owner/timezone snapshot cannot be changed after creation.
- New days show their own list; unfinished goals are retained on their original
  date, never silently moved or deleted. No automatic completion from timer data.
- Owner-only RLS, including admins: account administration and study-log access
  do not grant access to other people's personal goals.
- Track must belong to owner and be active when newly assigned. Existing
  archived links remain readable and can be retained or removed.
- Server validates all fields and expected account; database normalizes titles,
  stamps completion/updates and enforces ownership and immutable identity.
  Revision checks reject stale edits from concurrent tabs.
- Dashboard shows today's actual progress and first five goals with completion
  controls. Full CRUD and date history live on /goals.
- At local midnight / visibility return, refresh server data; writes retain the
  explicit displayed date so an open form cannot silently move to another day.
- Thai/English, Light/Dark, startup theme, accessible dialog/focus/error handling.
  No extra packages. Timer/fullscreen behavior remains intact.
