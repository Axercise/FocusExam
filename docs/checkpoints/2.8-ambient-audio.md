# 2.8 — Ambient audio

Approved: three CC0 ambience files (rain, ocean, white noise), play/pause,
selection, mute and volume; continue through same-site client navigation and
timer fullscreen; remember preferences without autoplay on reload.

## Contract

- Public files are bundled once; no database writes or streaming API keys.
  Catalog contains verified author/source/license metadata and local asset URLs.
- Only fetch/decode after explicit Play; one looping source per tab. A new
  tab's Play claims playback and pauses the previous tab when coordination is
  available. Saved preferences contain no playing state.
- Persistent root host survives App Router transitions. A global dock and timer
  audio settings provide controls away from the Dashboard, including fullscreen.
- Browser/device suspension displays a paused/interrupted state; user resumes.
  No promise of background playback when a mobile OS suspends the browser.
- Background volume/mute and timer chime volume are independent.
- Short gain ramps avoid abrupt starts/pauses; source files have a crossfaded
  boundary and bounded decode size. Lower background briefly for timer chimes.
- Thai/English, Light/Dark, keyboard/screen reader controls, reduced motion,
  bounded panel/dock layout and clear loading/retry errors.
- No package added. FFmpeg is used only by the optional asset preparation script.

Status: implemented and verified.
